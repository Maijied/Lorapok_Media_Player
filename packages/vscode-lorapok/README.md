# Lorapok Media Player for Visual Studio Code

Preview and stream all modern media formats directly inside Visual Studio Code with hardware acceleration, HLS/DASH support, ambient lighting, and audio equalization.

## Features

- 🎬 **Custom Media Editor**: Automatically opens `.mp4`, `.webm`, `.mkv`, `.avi`, `.mov`, `.flac`, `.mp3`, `.wav`, `.aac`, `.m3u8`, `.mpd` files.
- 📡 **Stream Player**: Run command `Lorapok: Open Media Stream URL` to play any live HLS or DASH stream URL directly inside your editor.
- 🌈 **Biological Ambient Glow**: Synchronizes ambient halo with video frames.
- 🎚️ **Audio Equalizer & Visualizer**: Built-in DSP sound filters.

## Installation

1. Download `lorapok-player-vscode-1.5.0.vsix` from [media.lorapok.tech](https://media.lorapok.tech) or GitHub Releases.
2. In VS Code, press `Ctrl+Shift+P` (or `Cmd+Shift+P`) and choose **Extensions: Install from VSIX...**
3. Select `lorapok-player-vscode-1.5.0.vsix`.
