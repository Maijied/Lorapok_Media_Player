# Lorapok Marketing Image Generation Guidelines

When the user asks to generate marketing images or UI mockups for the Lorapok Media Player (or any Lorapok ecosystem project), you MUST follow these aesthetic guidelines and use the `generate_image` tool with the provided prompt structures.

## Core Philosophy: The "Alive" Ecosystem
Lorapok Labs projects are built with an **engineering-first** approach that blends **biological UI concepts**, **sensory computing**, and practical utility. Interfaces must feel **alive**, highly responsive, and feature **high-clarity feedback loops**.

## Core Aesthetic (Always Include)
- **Vibe:** Biological aesthetics mixed with supercomputing, sensory computing, "alive" and highly responsive interfaces. Global industry-level quality, ultra-modern, futuristic.
- **Colors:** Dark mode / midnight space background, glowing neon cyan and electric purple accents.
- **UI Elements:** Glassmorphism, translucent floating panels, organic network nodes mixed with circuit boards, high-fidelity UI elements, and glowing sensory feedback loops (e.g. equalizers, pulsing data streams).

The background is a midnight space blending organic biological neural networks with high-tech supercomputing circuit boards. High fidelity, global industry standard UI design. No generic text."
